# RDS PostgreSQL(관계형 데이터 저장)

**API 데이터의 저장과 장애 복구를 담당하는 RDS PostgreSQL 구성**

DB 서브넷 그룹에 PostgreSQL 인스턴스를 배치하고 Multi-AZ로 주 인스턴스와 대기 인스턴스를 운영합니다. 공개 접근은 차단하며 API 보안 그룹에서 들어오는 데이터베이스 연결은 허용합니다.

## 1. Database Architecture(데이터베이스 구성)

| 항목 | 구성 |
|---|---|
| 엔진 | PostgreSQL |
| 데이터베이스 | `arcamap` |
| 인스턴스 식별자 | `arcamap-postgres` |
| 연결 | TCP 5432 |
| 가용성 | Multi-AZ |
| 스토리지 | 암호화된 gp3 |
| 공개 접근 | 비활성화 |

## 2. Availability and Protection(가용성과 보호)

- **장애 조치** — 주·대기 인스턴스를 다른 가용 영역에 두어 데이터베이스 장애에 대비합니다.

- **접근 통제** — DB 서브넷과 보안 그룹으로 데이터베이스 연결 경로를 제한합니다.

- **저장 공간 확장** — 초기 용량과 최대 용량을 따로 정하고 지정된 상한 내에서 저장 공간을 자동으로 늘립니다.

- **암호화** — 데이터를 저장하는 스토리지를 암호화합니다.

## 3. Operational Criteria(운영 기준)

| 항목 | 기준 |
|---|---|
| 자동 백업 | 3일 보존 |
| 삭제 보호 | 활성화 |
| 최종 스냅샷 | 삭제 시 생성 |
| 마이너 버전 자동 업그레이드 | 비활성화 |
| 메이저 버전 업그레이드 허용 | 비활성화 |
| 로그 내보내기 | PostgreSQL·업그레이드 로그 |

비밀번호는 일시적 변수와 write-only 인수로 전달하여 Terraform 상태·계획 파일에 저장하지 않습니다.
