# CloudWatch Log Group(로그 저장과 보존)

**📋 인프라 로그를 구분하여 저장하고 보존 기간을 관리하는 로그 그룹 구성**

데이터베이스와 API 실행 환경에서 생성하는 로그를 CloudWatch Logs의 로그 그룹으로 관리합니다. 로그 그룹마다 보존 기간을 정합니다. 장애 분석에 필요한 기록은 보관하고 기간이 지난 로그는 삭제합니다.

## 1. Log Organization(로그 구성)

| 구성 요소 | 역할 |
|---|---|
| **로그 그룹** | 같은 용도의 로그를 관리하는 단위 |
| **로그 스트림** | 로그 그룹 안에서 발생원별 기록을 구분하는 단위 |
| **보존 기간** | 수집한 로그를 유지할 기간 |

## 2. Operational Role(운영 역할)

- 💾 **데이터베이스 기록** — PostgreSQL과 업그레이드 로그를 어디에 얼마나 오래 저장할지 정합니다.

- 🩺 **실행 환경 기록** — 인스턴스 시스템 로그를 모아 서버 상태와 장애 원인을 파악하는 데 사용합니다.

- 📦 **보존 관리** — 지정한 기간이 지난 로그를 삭제해 기록을 보관할 범위를 정합니다.

## 3. Responsibility Boundary(역할 범위)

**로그 그룹에는 로그를 저장하고 보존합니다**. RDS의 로그 내보내기와 인스턴스의 로그 수집은 각 서비스에서 설정합니다. 이 설정에 따라 실제 로그를 로그 그룹에 보냅니다.
