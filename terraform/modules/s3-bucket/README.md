# S3 Bucket(객체 저장소)

**콘텐츠·배포 파일·로그를 저장하고 보존 기간을 관리하는 S3 구성**

객체를 용도별 버킷에 나누어 저장하고 암호화와 수명 주기를 설정합니다. 웹 콘텐츠·사진·접근 로그·API 배포 파일은 각각의 사용 목적에 맞는 버킷에 저장합니다.

## 1. Storage Roles(저장 역할)

| 용도 | 저장 대상 |
|---|---|
| 정적 콘텐츠 | 웹 화면을 구성하는 파일 |
| 사진 | 서비스에서 제공하는 사진 객체 |
| 접근 로그 | CloudFront 요청 기록 |
| API 배포 | 이미지 빌드에 사용하는 API 아카이브 |

## 2. Data Protection and Retention(데이터 보호와 보존)

- **저장 암호화** — S3에 저장하는 객체를 암호화합니다.

- **용도별 분리** — 콘텐츠 제공·배포·로그의 저장 위치를 구분합니다.

- **이전 버전 보존** — 사진 저장소에서는 객체의 이전 버전을 지정된 보존 기간 동안 보관합니다.

- **로그 정리** — 접근 로그 저장소에서는 객체 만료 기간이 지난 기록을 자동으로 삭제합니다.

## 3. Component Relationships(구성 요소 간 관계)

콘텐츠 버킷은 CloudFront의 오리진으로 사용합니다. API 배포 버킷은 Image Builder에 아카이브를 공급합니다. CloudFront가 콘텐츠를 읽는 경로와 배포 객체를 읽는 경로에 맞춰 각각 읽기 권한을 설정합니다.

버킷 용도에 따라 객체를 보존하는 방식도 다릅니다. 로그 만료와 사진의 이전 버전 보존에는 서로 다른 정책을 사용합니다.
