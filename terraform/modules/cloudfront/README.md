# CloudFront(정적 콘텐츠 제공)

**📦 S3 콘텐츠를 캐시하고 HTTPS로 제공하는 CDN 구성**

웹·지도·사진을 S3 오리진에서 가져와 CloudFront를 통해 제공합니다. OAC와 버킷 정책으로 오리진 접근을 제한합니다. 연결된 WAF는 요청을 검사하고 탐지 결과를 기록합니다.

## 1. Content Delivery Architecture(콘텐츠 전달 구성)

| 구성 | 역할 |
|---|---|
| **CloudFront 배포** | 콘텐츠 캐싱과 HTTPS 응답 |
| **S3 오리진** | 웹·지도·사진 원본 제공 |
| **OAC** | S3 오리진 요청 서명 |
| **버킷 정책** | 해당 배포의 오리진 접근 허용 |
| **WAF** | 웹 요청 검사와 결과 집계 |

## 2. Request Flow(요청 처리 흐름)

1. 브라우저가 CloudFront에 **HTTPS 요청**을 보냅니다.
2. WAF가 요청을 검사하고 판정 결과를 기록합니다.
3. **유효한 캐시가 있으면** 오리진 조회 없이 응답합니다.
4. 캐시 미스가 발생하면 OAC로 서명한 요청을 S3에 전달합니다.
5. 원본 콘텐츠를 가져와 브라우저에 HTTPS로 반환합니다.

## 3. Design Principles(설계 원칙)

- ⚡ **오리진 부하 감소** — 캐시된 콘텐츠로 응답해 S3 원본을 조회하는 횟수와 응답 지연을 줄입니다.

- 🔑 **접근 통제** — OAC와 버킷 정책으로 지정된 CloudFront 배포만 오리진에 접근하도록 제한합니다.

- 📈 **운영 기록** — CloudFront 접근 로그는 S3에, WAF 로그와 지표는 CloudWatch에 수집합니다.

## 4. Operational Constraints(운영 제약)

> **위협 탐지 방식**: 관리형 규칙의 판정은 Count 모드로 집계합니다. 탐지 건수를 곧바로 차단 건수로 해석하지 않습니다.
