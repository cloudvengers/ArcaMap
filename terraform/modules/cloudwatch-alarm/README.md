# CloudWatch Alarm(지표 기반 경보)

**📈 서비스 지표를 임계값과 비교하여 상태 변화를 감지하는 경보 구성**

데이터베이스와 API 인프라의 지표를 일정한 기간 단위로 집계합니다. 집계한 값이 지정된 조건에 맞는지에 따라 경보 상태를 판정합니다. 지표별로 대상·통계·평가 기간을 정해 자원 부족과 오류 징후를 감지합니다.

## 1. Alarm Composition(경보 구성)

| 구성 요소 | 역할 |
|---|---|
| **지표와 차원** | 감시할 값과 해당 리소스 식별 |
| **통계와 집계 기간** | 평균·최솟값·최댓값·합계 등으로 평가 값 계산 |
| **임계값과 비교 조건** | 상태 변화의 판정 기준 |
| **평가 기간과 위반 횟수** | 조건을 충족한 데이터 포인트의 수 반영 |
| **누락 데이터 처리** | 관측값이 없는 구간의 판정 방식 |

## 2. Monitoring Scope(감지 대상)

- 💾 **데이터베이스** — CPU 사용률·가용 메모리·가용 저장 공간의 경보로 자원 상태를 파악합니다. 연결 수 경보는 조건에 따라 사용합니다.

- 🩺 **인스턴스** — API 인스턴스 수·EC2 상태 검사·CPU 사용률로 실행 환경의 상태를 파악합니다.

- 🌐 **요청 처리** — ALB의 정상 대상 수와 ALB·API의 HTTP 5xx 지표로 요청 처리 이상을 감지합니다.

## 3. Evaluation Flow(판정 흐름)

1. 지정된 리소스의 **지표를 수집**합니다.
2. 집계 기간과 통계 방식에 따라 평가 값을 계산합니다.
3. 임계값 위반 횟수와 누락 데이터 처리 기준을 반영합니다.
4. 평가 결과에 따라 **CloudWatch 경보 상태**를 갱신합니다.

## 4. Operational Constraints(운영 제약)

> **알림 제약**: 현재는 CloudWatch 경보 상태만 표시하며 운영자에게 알림을 보내도록 설정하지는 않았습니다.
