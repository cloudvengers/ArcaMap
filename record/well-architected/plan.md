## 2. Assignment Conditions(공통 배포 조건)

### 기존 자료 활용

기둥별 담당자에게 기존 문서와 guide.md를 전달합니다. 기존 문서의 조사 대상과 확인 경로를 참고하되, 수치·판정·결론을 그대로 승계하지 않고 재조회한 근거로 새로 작성합니다.

### 집계 기간

- **KST**: 2026-09-14 00:00:00 이상, 2026-09-22 00:00:00 미만
- **UTC**: 2026-09-13 15:00:00 이상, 2026-09-21 15:00:00 미만
- 구성 확인 시점과 집계 기간을 구분합니다. 원자료의 시간 단위나 보존 범위로 공통 기간을 확보하지 못한 항목은 실제 확보 범위를 기록합니다.

### 재작성 기준

- 가이드 4절의 공통 목차와 절별 내용 범위, 5절의 판정·집계·근거 기준, 9절 전체 문서 스타일을 적용합니다.
- 1번에는 리소스·옵저빌리티 구성과 텔레메트리 수집 현황을, 4번에는 구성·운영 현상·사건의 근거와 상세 분석을 작성합니다.
- 실제 운영 사실과 판단 이유·영향·개선 방향을 연결하고 가이드에 따라 보고성 문장·메타 설명·불필요한 수치 나열을 정리합니다.
- 근거는 독자가 확인할 수 있는 리소스 설정·로그·지표·저장 경로·Terraform 정의 위치로 제시합니다.
- 비용 문서는 현재 운영을 기준으로 가이드 5.3절의 분석 범위와 제외 조건을 적용합니다.
