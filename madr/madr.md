- MADR 작성 양식
    
    페이지 제목에는 결정의 주제와 선택한 방안을 적습니다.
    
    ## 배경과 문제
    
    ### 배경
    
    - 결정의 목표와 현재 상황
    - 결정이 필요해진 이유
    
    ### 문제
    
    - 해결해야 하는 구체적인 문제
    - 문제를 뒷받침하는 구체적인 근거
    - 선택에 직접 영향을 주는 요구사항·제약
    
    ## 검토한 대안
    
    - 실제로 고려한 선택지
    
    ## 결정과 이유
    
    **선택: 방안 이름**
    
    - 선택한 이유
    
    ### 결과
    
    - 이점: 결정으로 얻는 효과
    - 제약: 감수하는 비용·위험·한계
- 양식의 근거와 적용 범위
    
    **기반: MADR 4.0.0의 최소 템플릿**
    
    - 배경과 문제: Context and Problem Statement
    - 검토한 대안: Considered Options
    - 결정과 이유: Decision Outcome
    - 결과: Consequences — 최소 템플릿에 포함된 선택 항목이며, 이 기록에서는 사용합니다.
    
    한국어 제목과 짧은 불릿을 사용합니다. 결과는 결정과 이유의 하위 항목으로 둡니다.
    
    상태·날짜 등 메타정보는 본문에 중복하지 않습니다. 작업 진행 상황과 실행 로그는 의사결정 본문에 넣지 않습니다.
    
    공식 MADR 소개
    
    기준 템플릿 · MADR 4.0.0 minimal
    
    전체 템플릿 · 선택 항목 안내

- 작성 원칙

    - 의사결정은 주제별로 별도 문서에 작성합니다.
    - 결정에 필요한 내용과 근거를 중요도에 따라 쓰고, 관련 없는 설명과 반복은 줄입니다.
    - 대안은 같은 기준으로 비교하고, 선택의 이유와 감수하는 부담을 구체적으로 설명합니다.
    - 구체적인 수치와 조건을 보존하고, 단위·범위·구성 항목을 함께 설명합니다.
    - 문서 안에서 맥락과 판단 근거를 이해할 수 있도록 용어와 관계를 명확히 설명합니다.
    - 관측한 사실과 해석을 구분하고, 핵심을 직접 전달하는 간결한 문장으로 씁니다.
    - 이전 문서로 연결하는 참조를 사용하지 않고 필요한 맥락을 각각 한 문장으로 설명합니다.
    - 설명 뒤에 주의사항을 붙이는 전개, 대조문 반복을 사용하지 않습니다.
